# 售后用户反馈多模态分析报告生成任务

你是一名数据分析师，需要对电商平台的售后用户反馈数据进行综合分析，并输出一份正式的 Word 分析报告。

## 输入文件说明

请仔细读取输入文件：

**售后反馈图片文件夹**（每张图片为用户提交的售后实物照片）：

```
/workspace/input/images/1.jpg
/workspace/input/images/2.jpg
/workspace/input/images/3.jpg
/workspace/input/images/4.jpg
/workspace/input/images/5.jpg
```

## 任务要求

请按照以下 SOP 步骤执行分析，并将结果输出为 Word 报告：

### 步骤一：数据审查与核查

仔细查看 `images/` 文件夹中的每张图片；

### 步骤二：问题类型分类

对每张售后实物照片进行分类，将其归入以下 5 个问题类型之一：

- **包装破损**：外包装、内包装受到物理损坏（压扁、破裂、受潮等）
- **商品瑕疵**：商品本体存在质量问题（色差、破损、功能异常等）
- **错发漏发**：收到商品与订单不符，或漏发配件/商品
- **物流延迟**：配送时效严重滞后，或物流信息异常
- **其他**：不属于以上四类的其他问题（如发票问题、赠品缺失、虚假反馈或证据不足等）


### 步骤三：生成 Word 分析报告

以 Word 格式输出一份分析报告，报告需包含以下三个主要章节：

**第一章：问题类型数量统计**
- 以表格形式列出各问题类型及其对应的反馈数量，表格包含且仅包含两列，表头从左至右依次为'问题类型' 和 '数量';
- 表内应包含全部 5 种问题类型（即使某类型数量为 0 也需列出），'问题类型'列填写顺序从上至下依次为'包装破损'、'商品瑕疵'、'错发漏发'、'物流延迟'、'其他'；

**第二章：典型图片示例**
- 针对每一个实际出现（数量 > 0）的问题类型，选取 1 张最具代表性的图片嵌入报告中
- 图片下方注明对应的 `feedback_id` 及该图片所反映的核心问题（一句话描述）

**第三章：归因结论与改进建议**
- 针对本次分析的结果，给出整体归因结论（分析哪类问题最为突出，可能的原因）
- 针对每个出现的问题类型，各提出至少 1 条具体可行的改进建议

## 输出文件

将分析报告保存为以下路径：

```
/workspace/input/answer/售后反馈分析报告.docx
```

请直接执行操作，不要问我任何问题，也不要让我做出进一步决策。如果遇到任何问题和决策点，请你自行解决。
