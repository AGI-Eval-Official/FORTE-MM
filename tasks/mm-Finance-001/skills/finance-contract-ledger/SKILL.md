# 财务合同管理台账 Skill

本 skill 帮助财务人员根据采购合同和银行电子回单，生成标准化的《合同管理台账》Excel 文件，覆盖应收账款跟踪、回款匹配、逾期预警等核心财务场景。

---

## 工作流程

### Step 1：读取并解析所有输入文件

收集用户提供的所有文件，包括但不限于：
- 采购合同（PDF、图片、Word、Excel 等格式）
- 银行电子回单（PDF、图片等格式）
- 其他补充说明文件

对每份合同，提取以下关键信息：
- 合同编号
- 客户公司全称（付款方全称）
- 合同名称
- 合同金额（总金额）
- 合同签订日期
- 付款条款：订金金额、订金付款条件（如"合同签订后X天内"）、尾款金额、尾款付款条件（如"验收合格后X天内"）

对每份银行电子回单，提取：
- 电子回单单号（流水号）
- 付款方名称
- 汇款金额
- 汇款日期
- 银行备注（用途/摘要）

---

### Step 2：以基准日期为准进行财务分析

基准日期由用户指定（如 2023年1月31日）。以该日期为截止点，对每份合同进行以下判断：

**订金分析：**
- 根据合同签订日期 + 订金付款条件，推算订金应付截止日期
- 若截止日期 <= 基准日期，则该订金"已到期"
- 对比银行回单，确认是否有对应实付记录

**尾款分析：**
- 根据合同约定的尾款付款条件，推算尾款应付截止日期
- 若截止日期 <= 基准日期，则该尾款"已到期"
- 对比银行回单，确认是否有对应实付记录

**逾期判断：**
- 若某笔款项已到期但未实付（或实付金额不足），则标记为"是"（逾期）
- 逾期天数 = 基准日期 - 应付截止日期（若未逾期则填 0 ）
- 超期欠款金额 = 应付金额 - 实付金额（若未逾期则填 0）
- 违约金：若合同中有违约金条款则按条款计算，否则填"暂无数据"

**回款匹配：**
- 将银行回单与合同进行匹配（依据：付款方名称、金额、日期、备注）
- 能匹配到合同的回单：在 sheet1 中填写实付信息，在 sheet2 中标记匹配状态为"已匹配"
- 无法匹配到合同的回单：在 sheet2 中标记匹配状态为"未匹配"，并在"建议匹配合同"列填写最可能对应的合同编号（若有）或"暂无数据"

---

### Step 3：生成 Excel 文件

使用 Python + openpyxl 库生成 Excel 文件，文件命名格式为：《YYYY年MM月合同管理台账》.xlsx（如《2023年01月合同管理台账》.xlsx）。

#### Sheet1命名为：合同应收台账
- **排列规则**：按合同签订日期从早到晚排序（升序）

表头字段（按顺序）：

| 字段名 | 填写规则说明 | 数据类型 | 示例 |
|:-------|:-------------|:---------|:-----|
| 合同编号 | 合同唯一标识 | 文本 | HT-2023-001 |
| 客户公司全称 | 客户完整名称 | 文本 | 上海XX科技有限公司 |
| 合同名称 | 合同项目名称 | 文本 | 服务器采购合同 |
| 合同金额 | 合同总金额（元） | 数字（保留2位小数） | 100000.00 |
| 合同签订日期 | 合同签署日期 | 文本（YYYY年MM月DD日） | 2023年01月05日 |
| 应付订金 | 若合同只约定比例未写金额，则填写“合同金额 × 订金比例%”后的数值；若合同明确写了金额，则直接填写  | 数字（保留2位小数） | 30000.00 |
| 订金付款条件 | 合同约定的订金支付条件 | 文本 | 合同签订后3日内支付 |
| 实付订金 | 银行回单中实际收到的订金金额（元） | 数字（保留2位小数） | 30000.00 |
| 订金付款时间 | 实际收到订金的日期 | 文本（YYYY年MM月DD日） | 2023年01月05日 |
| 应付尾款 | 合同金额 − 应付订金（元） | 数字（保留2位小数） | 70000.00 |
| 尾款付款条件 | 合同约定的尾款支付条件 | 文本 | 验收后3日内付清 |
| 尾款付款时间 | 实际收到尾款的日期，若没有该公司的尾款电子回单，则填写“暂无数据” | 文本（YYYY年MM月DD日） | 2023年01月05日 |
| 实付尾款 | 银行回单中实际收到的尾款金额（元） | 数字（保留2位小数） | 0.00 |
| 实际到账总金额 | 实付订金 + 实付尾款 | 数字（保留2位小数） | 30000.00 |
| 是否逾期 | 规则：若“实际到账总金额” < “合同金额”，则填“是”，并将该单元格背景色填充为**标准色黄色（RGB: 255,255,0）**；否则填“否”，无填充色 | 文本（是/否） | 是 |
| 超期欠款金额 | 根据以下公式计算后的数值：`合同金额 − 实际到账总金额` | 数字（保留2位小数） | 70000.00 |
| 违约金 | 按合同约定计算后填写相应数值（若无约定填0） | 数字（保留2位小数） | 0.00 |
| 逾期天数 | 当前日期（2023-01-31）− 尾款付款时间（若已逾期） | 数字（整数） | 11 |
| 备注 | 若“是否逾期”为“否”，则填写“正常”；若为“是”，则填写催收跟进状态或下一步行动建议，如：“需电话催收”、“需去客户公司面谈”、“已发催款函”、“客户承诺X月X日前付款”、“已移交法务”等 | 文本 | 正常 |

#### Sheet2 命名为：非合同进账
- **排列规则**：按电子回单日期从早到晚排序（升序）
- **填写规则**：本表仅记录**无法与 Sheet1（合同应收台账）中任何合同匹配**的电子回单。若该电子回单已在合同台账中找到对应合同，则不在本表中记录。

| 字段名 | 填写规则说明 | 数据类型 | 示例 |
|:-------|:-------------|:---------|:-----|
| 电子回单单号 | 银行电子回单的唯一编号 | 文本 | ZG-202301001 |
| 付款方名称 | 汇款方全称 | 文本 | 上海XX科技有限公司 |
| 汇款金额 | 汇款金额（元） | 数字（保留2位小数） | 30000.00 |
| 汇款日期 | 汇款日期 | 文本（YYYY年MM月DD日） | 2023年01月05日 |
| 银行备注 | 回单中的备注信息 | 文本 | 货款 |
| 匹配状态 | 已匹配/未匹配 | 文本 | 已匹配 |
| 建议匹配合同 | 建议匹配的合同编号。若无法匹配到任何合同，填写“暂无数据” | 文本 | HT-2023-001 |
| 待核销金额 | 若“建议匹配合同”为“暂无”，则填写“暂无数据”；若“建议匹配合同”中已匹配到具体合同编号，则填写根据以下公式计算后的数值：`合同总价 − 实际到账金额`，保留2位小数 | 数字（保留2位小数） / 文本 | 待处理 |
| 处理状态 | 已核销/待处理 | 文本 | 已核销 |

## 注意事项

- 若合同中未明确区分订金和尾款，而是一次性付款，则将全部金额填入"应付尾款"，订金相关字段填"暂无数据"
- 若同一客户有多份合同，每份合同单独占一行
- 若一份回单对应多份合同（拆分付款），在 sheet2 中分行记录，并在备注中说明
- 若合同付款条件涉及里程碑（如"验收合格后"），而验收状态未知，则在备注中注明"付款条件待确认"，逾期判断暂按"否"处理
- 所有金额单位统一为"元（人民币）"，若原始文件为万元，需换算后填入
**重要说明：本表所有数值必须直接写入计算后的数值结果，禁止写入 Excel 公式字符串（如 `=SUM(...)`）。**
