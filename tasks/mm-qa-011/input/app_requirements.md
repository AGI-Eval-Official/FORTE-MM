# 电商 Web 应用功能需求文档

## 系统概述

本系统为一个标准电商 Web 应用，包含用户认证、商品浏览、购物车、结算支付等核心功能模块。前端基于单页应用（SPA）架构，所有页面路由均为客户端路由。

## 页面与路由定义

| 页面名称 | 路由路径 | 核心功能 |
|----------|----------|----------|
| 登录页 | `/login` | 用户名密码登录、表单校验、错误提示 |
| 首页 | `/home` | 商品推荐列表、搜索入口、导航菜单 |
| 搜索结果页 | `/search?q={keyword}` | 关键词搜索、结果列表、分页 |
| 商品详情页 | `/product/:id` | 商品信息展示、规格选择、加入购物车 |
| 购物车 | `/cart` | 商品列表、数量修改、删除、去结算 |
| 结算页 | `/checkout` | 收货地址、订单确认、提交订单 |
| 支付页 | `/payment` | 支付方式选择、支付确认 |
| 订单成功页 | `/order/success` | 订单号展示、继续购物入口 |
| 支付失败页 | `/order/fail` | 失败原因、重试入口 |
| 个人中心 | `/profile` | 用户信息、修改密码 |
| 订单列表 | `/orders` | 历史订单、订单状态 |

## 关键交互行为规范

### 登录模块
- 用户名和密码均为必填项，为空时提交按钮不可点击或提示错误
- 密码错误时页面显示错误提示文案，文案包含"用户名或密码错误"
- 连续错误 3 次后账号锁定，显示"账号已锁定，请 30 分钟后重试"
- 登录成功后跳转至 `/home`，LocalStorage 中存储 `auth_token` 字段

### 搜索模块
- 搜索框输入关键词后按回车或点击搜索按钮触发搜索
- 搜索结果页 URL 包含 `q` 参数，如 `/search?q=手机`
- 搜索结果列表中每个商品卡片包含：商品名称、价格、评分
- 无结果时显示"未找到相关商品"提示

### 购物车模块
- 商品详情页点击"加入购物车"后，购物车图标数量 +1
- 购物车为空时点击"去结算"按钮，显示提示"购物车为空，请先添加商品"，不跳转
- 购物车商品数量可修改（+/-按钮），修改后小计金额实时更新
- 删除商品后列表实时刷新

### 结算与支付模块
- 结算页必须展示收货地址，地址为空时提示"请填写收货地址"
- 提交订单成功后跳转至 `/payment`，URL 包含 `orderId` 参数
- 支付成功后跳转至 `/order/success`，页面展示订单号（非空字符串）
- 支付超时（>30s）或被拒绝时跳转至 `/order/fail`，展示失败原因

## 测试路径定义

| 路径ID | 路径名称 | 起点 | 终点 | 类型 |
|--------|----------|------|------|------|
| PATH-01 | 正常登录流程 | `/login` | `/home` | 正常路径 |
| PATH-02 | 登录失败锁定 | `/login` | `/login`（锁定提示） | 异常路径 |
| PATH-03 | 搜索商品 | `/home` | `/search` | 正常路径 |
| PATH-04 | 加入购物车 | `/product/:id` | `/cart`（数量+1） | 正常路径 |
| PATH-05 | 正常结算下单 | `/cart` | `/payment` | 正常路径 |
| PATH-06 | 支付成功 | `/payment` | `/order/success` | 正常路径 |
| PATH-07 | 支付失败 | `/payment` | `/order/fail` | 异常路径 |
| PATH-08 | 空购物车结算 | `/cart` | `/cart`（提示） | 边界条件 |
